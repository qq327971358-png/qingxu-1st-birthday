# 王清许宝宝 · 周岁宴电子邀请函

一个手机端 H5 邀请函，微信里打开即可浏览、转发。

## 一、本地预览

双击 **`预览邀请函.bat`**，会自动打开浏览器预览（手机请连同一个 WiFi，访问电脑的 `http://电脑IP:8001`，用手机 Chrome 或微信打开）。

> 关闭弹出的黑色窗口 = 停止预览。

## 二、换成宝宝的真实照片

1. 把照片（6~15 张，JPG 格式）放进 **`宝宝照片`** 文件夹。
   - iPhone 照片若是 HEIC：设置 → 相机 → 格式 → 选「兼容性最佳」；或通过微信「原图」发送后再保存。
   - 竖版照片效果最好；脚本会自动居中裁成 3:4。
2. 双击 **`更新照片.bat`**。
3. 脚本会生成 `assets/img/cover.jpg`（封面）和 `photo-01.jpg…`，并更新 `assets/img/manifest.json`。
4. 刷新预览页面即可看到。
5. 标签：文件名写成 `02-1个月.jpg` 时，直接显示「1个月」；没有数字前缀时，按拍摄时间自动生成（满月 / 百天 / 4个月…）。
6. 排序：文件名以 `01-`、`02-`… 开头时按数字顺序排列；否则按拍摄时间。想指定封面，把那张照片命名为 `封面.JPG`。
7. 想自己改某张的标签：在 `宝宝照片` 里新建 `labels.json`，例如 `{"IMG_1234.JPG": "第一次看海"}`。
8. 某张裁剪位置不理想（比如人脸偏到边上）：在 `宝宝照片` 里新建 `crop.json`，例如 `{"02-1个月.jpg": {"x": 0.95}}`。`x` 从 0（最左）到 1（最右），默认 0.5 居中；竖图还可加 `"y"`（默认 0.42 偏上）。

## 三、换背景音乐

把选中的音乐文件重命名为 `bgm.mp3`，覆盖 **`assets/audio/bgm.mp3`** 即可。

当前默认：Kevin MacLeod 的《Teddy Bear Waltz》（CC BY 4.0），页脚已署名。
想对比三首候选曲目，本地预览时在手机上打开 `http://电脑IP:8001/tools/music.html` 试听。
若换成 CC BY 曲目，请同步修改 `index.html` 页脚的 `music-credit` 文案；CC0 曲目可删除该行。

## 四、字体（前三页）

封面、邀请函、照片墙三页用的是 **站酷快乐体**（ZCOOL KuaiLe，圆圆胖胖的手写体）；标题字「王清许」「邀请函」也是用它渲染成三色糖果贴纸 PNG 的。倒计时数字单独用 **Baloo 2 ExtraBold**（圆滚滚的数字，快乐体的数字太斜、不好认）。

- 网页字体：`assets/fonts/candy-subset.woff2`（只保留前三页用到的 217 个字符，15KB）、`assets/fonts/candy-num.woff2`（数字，2KB）。
  改了前三页的文字后，如果出现缺字，重新生成一次：`python tools/make_font.py`（需要 `tools/fonts/` 下的 `ZCOOLKuaiLe-Regular.ttf`、`Baloo2-wght.ttf` 两个源文件，不入仓库）。
- 标题字 PNG：`python tools/make_titles.py`（同样需要站酷快乐体源文件）。
- 授权：两款字体均为 SIL Open Font License（OFL），免费商用、无需署名。
- 字库里没有「祎」字（宝妈名字），脚本用同字体的「礻」+「韦」拼了一个，效果与整体一致。
- 「清」字在快乐体里笔画容易糊，标题字里单独换成 Windows 自带幼圆加粗描边，看起来更清楚。

## 七、文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面内容（5 屏文字） |
| `css/style.css` | 样式与动画 |
| `js/main.js` | 翻页、倒计时、照片墙、复制地址 |
| `js/particles.js` | 背景星屑 / 光尘 / 花瓣 |
| `js/effects.js` | 3D tilt、彩带、烟花、摇一摇 |
| `js/player.js` | 背景音乐控制 |
| `tools/process_photos.py` | 照片压缩与 manifest 生成 |
| `tools/make_titles.py` | 生成糖果色标题字与分享封面 |
| `tools/make_font.py` | 裁剪站酷快乐体、生成倒计时数字字体 |
| `assets/fonts/candy-subset.woff2` | 前三页用的站酷快乐体（15KB） |
| `assets/fonts/candy-num.woff2` | 倒计时数字用的 Baloo 2（2KB） |
| `宝宝照片/` | 放原始照片（不会上传到仓库） |

> 装饰小元素（气球 / 熊熊 / 兔兔 / 星星 / 爱心 / 烟花 / 蛋糕 / 小花）是 `index.html` 顶部的一套内联 SVG（`#art-balloon`、`#art-bear`、`#art-bunny`、`#art-spark`、`#art-heart`、`#art-fw`、`#art-cake`、`#art-flower`），哪里出现就在对应页面里写一行 `<svg class="…"><use href="#art-…"/></svg>`；位置、大小、漂浮动画都在 `css/style.css` 末尾的装饰区。想去掉某个小装饰，删掉对应的那行 `<svg>` 即可。
